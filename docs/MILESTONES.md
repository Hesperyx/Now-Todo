# 里程碑

本文档把 [PRD](PRD.md) 的首版范围拆成可交付、可验收的阶段。

**规则**：

- 每个里程碑的「验收标准」必须**全部**满足才可标记完成。不满足就顺延，不放水。
- 不在当前里程碑范围内的功能，一律不做——即使顺手。范围蔓延是 PRD 点名的头号风险。
- 增强项（小组件、日历、统计、多语言、无障碍）**不在 1.0.0 的里程碑序列内**，见文末。

状态图例：`已完成` · `进行中` · `未开始`

## M1 · 数据层

**状态**：未开始

**交付物**

- `lib/data/database/` 下全部 Drift 表定义：`tasks`、`task_lists`、`tags`、`task_tags`、`subtasks`、`reminders`、`recurrence_rules`、`settings`。
- 外键约束与 `ON DELETE CASCADE`（任务删除时级联清理子任务、提醒、标签关联）。
- 索引：`tasks(status)`、`tasks(due_date)`、`tasks(list_id)`、`subtasks(task_id)`、`reminders(task_id)`、`task_tags(tag_id)`。
- 每个聚合的 DAO，以及 `lib/data/repositories/` 下的仓储接口与实现。
- 领域模型与枚举（`Priority`、`TaskStatus`、`RecurrenceFrequency`、`RepeatType`）。
- `MigrationStrategy` 骨架 + `dart run drift_dev schema dump` 生成的 schema 快照。

**验收标准**

- [ ] `AppDatabase` 能在内存模式（`NativeDatabase.memory()`）下打开，用于测试
- [ ] 任务删除后，其子任务 / 提醒 / 标签关联记录全部消失（有测试）
- [ ] 仓储层不向上层抛出 Drift 生成类型（`features/` 的 import 静态检查通过）
- [ ] `flutter analyze` 零告警
- [ ] 仓储测试覆盖增删改查与级联删除

## M2 · 任务核心闭环

**状态**：未开始

**交付物**

## M3 · 组织能力

**状态**：未开始

**交付物**

## M4 · 结构化任务

**状态**：未开始

**交付物**

- 子任务：新增、勾选、排序、删除；父任务展示 `已完成/总数` 进度。
- 重复任务：每天 / 每周 / 每月 / 自定义（间隔 + 指定周几 + 结束条件）。
- `lib/core/recurrence/` 下的重复规则计算，纯函数、可单元测试。
- 任务完成后按规则生成下一次实例（或推进其截止日期），具体策略在实现前确定并写入 ARCHITECTURE。

**验收标准**

- [ ] 子任务全部勾选时父任务进度显示正确；父任务完成不强制子任务完成（反之亦然）
- [ ] 重复规则覆盖并测试以下边界：跨月、月末（1/31 → 2/28）、闰年、按周几、按次数结束、按日期结束
- [ ] 编辑重复任务时，可选择「仅此一次」或「此后全部」
- [ ] 结束重复不会删除历史已完成实例
- [ ] 重复规则计算有完整的单元测试（PRD 风险 9 点名项）

## M5 · 本地提醒

**状态**：未开始

**交付物**

- `flutter_local_notifications` 初始化、Android 通知渠道、Android 13+ 通知权限请求流程。
- `timezone` + `flutter_timezone` 时区初始化与变更监听。
- 提醒调度器：把 `reminders.remind_at`（UTC 毫秒）转换为设备时区绝对时刻并调度。
- 设置项：提醒总开关、通知权限状态展示与引导。
- 时区变更后重新调度未过期提醒。

**验收标准**

- [ ] Android 真机/模拟器上能按时收到通知
- [ ] 权限被拒绝时应用完全可用，仅在设置页给出可关闭的提示
- [ ] 设备时区变更后，未过期提醒按新时区重新计算
- [ ] 删除任务时其提醒被一并取消
- [ ] Android 精确闹钟权限被拒时退化为非精确调度，且 UI 上有说明（不静默不响）
- [ ] 提醒时间换算逻辑有单元测试

## M7 · 导入导出

**状态**：未开始

**交付物**

- JSON 全量导出（格式见 ARCHITECTURE §8）：写文件 → `share_plus` 分享 / 保存。
- JSON 导入：`file_picker` 选文件 → 整体校验 → 事务内落库。
- 导入模式：合并（按 `id`，保留较新的 `updatedAt`）/ 覆盖。
- `exportVersion` 与数据库 `schemaVersion` 分离管理；高版本拒绝、低版本走升级函数链。

**验收标准**

- [ ] 空库可正常导出（产出合法 JSON，不崩溃）
- [ ] 含清单 / 标签 / 子任务 / 提醒 / 重复规则的完整数据可导出并原样恢复
- [ ] 损坏 JSON、缺字段、`exportVersion` 过高 —— 均给出可读错误且**不写入任何数据**
- [ ] 导入为单事务，中途失败后数据库保持导入前状态
- [ ] 导出文件可被第三方工具解析（格式公开）
- [ ] 导入导出有覆盖上述场景的单元测试

## 增强项（1.0.0 之后）

以下内容不在首版里程碑内。启动任一项之前需先更新 PRD 并开 Issue 讨论范围。

| 项 | 备注 |
| --- | --- |
| 桌面小组件 | 依赖原生实现（Android App Widget；iOS WidgetKit 随 iOS 恢复），成本较高 |
| 日历视图 | 月视图聚合，需要新的查询与缓存策略 |
| 统计面板 | 完成率、连续天数等，注意不要引入云端统计 |
| 多语言 | 文案迁入 `l10n/`，先做 zh-Hans / en |
| 无障碍优化 | 语义标签、TalkBack / VoiceOver 走查、动态字体 |
| 主题色自定义 | Material 3 动态取色 + 手动色板 |
| 手势操作 | 滑动完成 / 删除 / 顺延 |
| 快速添加 | 主屏快捷方式、分享目标接入 |
| CSV 导出 | 复用导出层，加一个序列化器 |
| 可选匿名崩溃统计 | **默认关闭**，首次启动询问，绝不采集任务内容 |
