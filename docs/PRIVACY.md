# 隐私政策

**生效日期**：2026-10-08　　 **适用版本**：1.0.0 及以后

## 一句话总结

Now Todo **不收集任何数据**。它没有联网权限，所以就算想发也发不出去。

## 应用收集什么

什么都没有。具体到「通常会被采集的那些东西」：

| 常见做法 | 这个应用 |
| --- | --- |
| 账号、手机号、邮箱 | 没有账号系统，不需要注册 |
| 任务标题、备注、清单、标签 | 只存在你的手机上，从不上传 |
| 专注记录、使用时长、点击行为 | 同上；「统计」页的数字是当场从本机数据库算出来的 |
| 崩溃日志、性能数据、诊断信息 | 没有接入任何崩溃上报 SDK |
| 设备标识（IMEI、广告 ID、Android ID） | 不读取 |
| 通讯录、位置、相机、麦克风、相册 | 不申请这些权限 |
| 广告 | 没有广告，也没有广告 SDK |
| 第三方分析（埋点、A/B 实验） | 一个都没有 |

## 数据存在哪里

- 任务、清单、标签、提醒、重复规则与专注记录都存在本机的 SQLite 数据库里
  （应用私有目录，路径形如 `/data/data/io.github.hesperyx.nowtodo/databases/now_todo`）。
  其他应用读不到它，除非设备已经 root。
- 桌面小组件显示的内容放在应用私有的 `SharedPreferences` 里，同样只在本机。
- **卸载应用会连同这些数据一起删除**。想留住数据，请先在「设置 → 数据 → 导出数据」
  里存一份备份；重装后用「导入数据」恢复。

## 应用申请了哪些权限，为什么

| 权限 | 用来做什么 | 不给会怎样 |
| --- | --- | --- |
| 通知（`POST_NOTIFICATIONS`） | 到点把提醒发出来 | 提醒不会出现，其他功能照常 |
| 精确闹钟（`SCHEDULE_EXACT_ALARM`） | 让提醒落在你设的那一分钟，而不是「大概那段时间」 | 提醒会晚几分钟到几小时 |
| 开机启动（`RECEIVE_BOOT_COMPLETED`） | 重启后把还没到点的提醒重新排上 | 重启后所有提醒消失，要手动再设 |
| 前台服务（`FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE`） | 专注计时进行中在通知栏显示实时进度，应用被划掉也不中断 | 划掉应用时专注计时会断 |

**没有申请 `INTERNET` 权限。** 这是最关键的一条：没有它，应用在系统层面就无法建立任何
网络连接——不存在「偷偷上传」的可能，这一点由 Android 保证，不是靠承诺。
（`test/android/focus_foreground_service_test.dart` 里有一条用例专门盯着这个权限，
哪天有人加回去，CI 会先失败。）

## 什么时候数据会离开设备

只有一种情况，而且由你触发：

- **导出数据**：应用把数据库写成一个 JSON 文件，然后交给系统的分享面板。文件去哪由你
  决定——存到本机、发给自己的另一台设备、传进网盘，都由系统与你选的目标应用完成，
  Now Todo 自己不联网。导入时反过来：用系统文件选择器挑一个文件读进来。

另外，「关于」页里的两个链接（开源仓库地址、捐赠页）会用浏览器打开。这一步是浏览器
在访问那些网站，按它们各自的隐私政策行事，与 Now Todo 无关。

## 儿童

应用不含广告、不做用户画像、不收集任何个人信息，因此不涉及儿童个人信息的收集与使用。

## 政策变更

这份政策如果修改，会随新版本一起发布，并在这里更新生效日期。由于应用不联网，历史版本
不会「自动接受」新政策——每个版本对应的就是它自己那份说明。
